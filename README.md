# Radar-Delivery
Radar Delivery 🚀: Sistema SaaS completo de delivery para comércios locais em Manaus. Crie sua vitrine virtual própria sem taxas abusivas! Inclui catálogo interativo, painel de pedidos em tempo real, gestão financeira com Pix/PDF, controle de clientes e criação multi-loja automatizada. Desenvolvido em PHP, MySQL e Tailwind.
